# Tasks

## 1. 开孔遮罩改由 SurfaceView 自己画

- [x] 1.1 在 `TerminalSurface.onDraw` 里画遮罩：原生 surface 尚无缓冲时画遮罩
      （离开时的画面），有缓冲时不画
- [x] 1.2 遮罩位图与来源一一对应（来源是运行期发布的那一帧对象，身份变了才重建位图）
- [x] 1.3 遮罩与当前 surface 尺寸不一致时不用（错位的位图比没有遮罩更糟）
- [x] 1.4 没有可复现的上一帧时铺终端底色，不让开孔透出后方桌面

## 2. 组合层不再画遮罩

- [x] 2.1 去掉组合层按「有没有缓冲区」切换的底色：那层底色在洞里必被平台的打洞抹掉
      （实测组合层涂的底色只在 `SurfaceView` 之外的边距上可见）
- [x] 2.2 去掉组合层画的遮罩位图（同一理由）
- [x] 2.3 组合层只把「有没有缓冲」这个事实推给视图，好让视图在事实翻转时及时重绘

## 3. 用例

- [x] 3.1 `TerminalHoleCoverInstrumentedTest` 逐像素比对开孔与遮罩帧（实测吻合 100%）
- [x] 3.2 另钉颜色种数下限：单靠吻合比例放不住平底色（终端画面绝大部分是底色，
      平底色与遮罩的底色那一部分照样吻合）
- [x] 3.3 容差按合成管线对开孔区域那次色彩变换的幅度给（实测
      `screen = 0.878 × buffer + 31`，最暗的底色差 27 级）
