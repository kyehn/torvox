# Design

## 研究坐标

| 对象 | 坐标 | 用途 |
| --- | --- | --- |
| `warpdotdev/warp` | master 快照（无发布标签，提交日期 2026-11-20） | 形态与架构、终端模拟层、测试资产、许可证与治理 |
| 本仓 | 工作树 | 接缝现状与规范裁定 |

本仓约定文档不写 git 提交号，故坐标用快照标识。

## 取舍记录

- **只做对照，不做移植**：Warp 与本仓在 VT 核、渲染栈、目标平台三主线都不重合，移植代码没有对象；
  本变更只交付评估与裁定，不交付实现。
- **VT 核不采纳**：Warp 自研终端模型（alacritty 血统 + `vte` 状态机）与本仓 `libghostty-vt` 单一来源相悖。
- **渲染栈不采纳**：Warp 主走 Metal，wgpu 仅实验性；本仓 Vulkan 唯一、无回退。
- **测试资产不采纳**：`ref_tests` 期望值由实现自身产出（门槛 1 成立）；`escape_sequences_tests` 断言上游字节
  属不测依赖行为。
- **秘密脱敏登记为候选**：技术上可落地但 `DESIGN.md` 未声明，维持未立项，先登记。
- **许可证不作为判定依据**：按本仓口径（不检查依赖许可证、不引入许可证文件），AGPL/MIT 只作事实登记。

## 方法步骤概览

报告按「形态与架构 → 逐项对照 → 可采纳性判定 → 事实/推论/未知 → 不做清单 → 复现方式」组织；
可采纳性判定按测试资产门槛（1/2/3）与功能面（PROHIBITED/未声明/不采纳/参照）两套口径。
