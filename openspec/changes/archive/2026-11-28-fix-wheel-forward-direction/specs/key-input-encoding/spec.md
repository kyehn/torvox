## ADDED Requirements

### Requirement: 转发滚轮与本地回滚同向

转发的滚轮方向 MUST 与本地回滚同一语义（内容跟随手指）：手指下移（进入更早的
历史）MUST 编码为滚轮上，手指上移（回到更新的内容）MUST 编码为滚轮下。同一个
手势 MUST NOT 因前台程序是否启用鼠标上报而朝相反方向滚动；两路径的亚行余量
MUST 共用同一符号约定（正 = 更旧的待消化位移），使手势中途在两条路径间切换时
不产生跳变。

余量属于手势：手势结束时 MUST 归零，MUST NOT 泄漏到下一次输入——转发路径不走
本地回滚，余量不经本地滚动管道归零，残留会被下一次滚动当成待消化的位移。

#### Scenario: 同一手势在两条路径上方向一致

- **WHEN** 同一拖动分别在前台程序启用与未启用鼠标上报时发生
- **THEN** 手指下移 MUST 编码为滚轮上、手指上移 MUST 编码为滚轮下；两路径的
      亚行余量 MUST 共用「正 = 更旧的待消化位移」的符号约定，切换路径时不跳变

#### Scenario: 手势结束的余量不泄漏到下一次输入

- **WHEN** 一次转发滚轮的拖动以未走满一档的亚行余量结束
- **THEN** 该余量 MUST 在手势结束时归零，下一次滚动 MUST NOT 把它计入位移
