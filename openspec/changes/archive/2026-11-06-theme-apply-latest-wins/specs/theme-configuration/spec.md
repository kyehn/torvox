## MODIFIED Requirements

### Requirement: 应用与错误处理

主题选择 MUST 即时生效。主题名显示于预览框下方，长名 MUST 完整显示，
MUST NOT 在预览框内。设置中存着无法解析的名字 MUST 清除对应键，
MUST NOT 静默替换为默认主题。

主题解析与下发 MUST 以最新设置为准：并发到达的主题变更中，终态主题 MUST 是
最后一次变更对应的主题，MUST NOT 让较早解析出的主题晚于较晚解析出的主题落地。
新建会话 MUST 使用当前生效的主题，MUST NOT 使用建会话之前解析出的旧主题。

#### Scenario: 选择即时生效

- **WHEN** 选择另一主题
- **THEN** 终端配色立即按新调色板渲染

#### Scenario: 并发主题变更以最新主题为准

- **WHEN** 多个主题设置在短时间内连续变更，各次变更并发下发
- **THEN** 终态主题是最后一次变更对应的主题，旧主题不会晚到并覆盖它

#### Scenario: 新建会话使用当前主题

- **WHEN** 当前生效的是日间主题时新建会话
- **THEN** 新会话使用当前生效的日间主题，不使用建会话之前解析出的旧主题

#### Scenario: 主题切换全屏重绘不留残影

- **WHEN** 终端主题切换（含日夜跟随切换）
- **THEN** 所有行按新主题底色重绘，旧底色像素数低于阈值，不残留

#### Scenario: 预览名在框下方

- **WHEN** 预览主题
- **THEN** 主题名在预览框下方完整显示

#### Scenario: 无效主题名被清除

- **WHEN** 设置中的主题名在清单中不存在
- **THEN** 该设置键被清除，后续读取回落默认，不静默替换
