# text-selection Specification

## Purpose

文本选择的启动（长按/多击）、控制柄拖动与边缘滚动、选择菜单内容与锚定、全选与复制、打开链接/文件的对外行为契约，对齐 `DESIGN.md` 文本选择条款与 termux-app、ghostty-android-terminal 参考实现。

## MODIFIED Requirements

### Requirement: 长按启动选择

长按非空文本 MUST 经上游终端词选择语义选中该词并反色，随后出现左右控制柄；长按空白或无可选词的单元格 MUST 仅反色被长按单元格。落点为宽字符后半格时 MUST 先归到该字符起始列再判定空白，使选词而非仅粘贴菜单生效。单元格↔字符的列映射 MUST 取自网格单元的宽度事实，MUST NOT 由行文本反推。选择状态 MUST 由终端持有并随滚动与新输出跟随文本。

#### Scenario: 长按选词

- **WHEN** 长按英文单词
- **THEN** 选区覆盖该词（按上游词边界语义）且出现左右控制柄

#### Scenario: 长按宽字符后半格

- **WHEN** 长按双宽字符的后半格
- **THEN** 按该字符起始列选词，而非弹出仅粘贴菜单

#### Scenario: 长按空白单元格

- **WHEN** 长按无内容单元格
- **THEN** 仅该单元格反色并显示粘贴菜单

#### Scenario: 宽字符后的空白判定不漂移

- **WHEN** 行内先出现宽字符，其后单元格为空格
- **THEN** 该空格判为空白，判定位移不随宽字符个数累加

#### Scenario: 选区随滚动跟随

- **WHEN** 选择激活期间新输出将文本推进回滚区
- **THEN** 选区端点跟随文本移动

### Requirement: 控制柄拖动

拖动控制柄 MUST 实时更新选区，宽字符单元格 MUST 吸附不被拆分，该吸附 MUST 由网格单元宽度事实给出而非由行文本字符位置推算；一端越过对侧端点 MUST 交换两端归属；拖动期间选择菜单 MUST 隐藏，抬手 MUST 按新选区几何重显菜单。

#### Scenario: 宽字符吸附

- **WHEN** 手柄停在双宽字符的后半格
- **THEN** 手柄吸附至该字符起始列

#### Scenario: 行内多个宽字符均吸附

- **WHEN** 行内前一个字符也是双宽字符且手柄停在后一个宽字符的后半格
- **THEN** 手柄吸附至后一个字符的起始列而非更左的列

#### Scenario: 交叉交换归属

- **WHEN** 起点手柄越过终点手柄
- **THEN** 两端归属交换且选区保持非空

#### Scenario: 拖动隐藏菜单

- **WHEN** 抓住控制柄开始移动
- **THEN** 选择菜单不可见；抬手后菜单按新选区重显
