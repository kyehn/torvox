## ADDED Requirements

### Requirement: 同一字体文件只装入字体库一次

同一字体文件 MUST 只装入渲染字体库一次。`fonts.xml` 的声明单位是「面」而字体库的
单位是「文件」：一个 TTC 装一次即含其全部面，故 `lang` 块按字重重复声明的多个条目
指向同一份文件，只需装一次。

去重 MUST 按解析后的路径进行：同一份文件被不同族以不同文件名声明时（用户投放字体
与系统字体同名即是一例）也算同一份，MUST NOT 按声明里的文件名进行。

理由是资源与代价都按倍数膨胀：一份 CJK TTC 被 mmap 并解析多次，字体库里多出同族
同字形的重复面，而全库扫描找字形（`find_glyph_anywhere`）逐面重建 charmap，重复面
把这条本就以毫秒计的路径按倍数放大。

#### Scenario: 同一文件只装一次

- **WHEN** `fonts.xml` 的 `lang` 块把同一个字体文件按多个字重重复声明
- **THEN** 该文件在渲染字体库中只装入一次，库内无同源重复面

#### Scenario: 跨族声明的同一文件只装一次

- **WHEN** 主字体族与区域族声明了同一个字体文件
- **THEN** 该文件在渲染字体库中只装入一次
