## MODIFIED Requirements

### Requirement: 菜单锚定与样式

菜单 MUST 位于选区附近且不与选区矩形相交：选区变更后 MUST 立即重显并重锚，贴视口边缘 MUST 翻转到另一侧，两侧均无空间时 MUST 隐藏。菜单整体 MUST 落在视口之内；选区整体滚出视口时上下两处落点都在视口外，MUST 与「两侧均无空间」同等处理（隐藏），MUST NOT 把菜单添加到视口之外。菜单样式 MUST 使用 Material 3 主题属性，MUST NOT 硬编码颜色。

#### Scenario: 全选后重锚

- **WHEN** 通过菜单触发全选
- **THEN** 菜单立即按新选区重锚且与选区矩形不相交

#### Scenario: 贴顶翻转到下方

- **WHEN** 选区贴住视口顶部使上方无空间
- **THEN** 菜单翻转到选区下方且不遮挡选区

#### Scenario: 两侧无空间时隐藏

- **WHEN** 选区高度使上下方均无处放置菜单
- **THEN** 菜单隐藏

#### Scenario: 选区滚出视口时隐藏

- **WHEN** 选中一段文本后把视口翻到选区之外，使选区整体落在视口之上或之下
- **THEN** 菜单隐藏，而不是被添加到视口之外的坐标（越界窗口不抛错也不可见，
  外部表现是「选中了却没有菜单」）

#### Scenario: 选区下缘越出视口仍锚在上方

- **WHEN** 选区下缘越过视口底缘而上方落点整体仍在视口内
- **THEN** 菜单锚在选区上方且不与选区相交

#### Scenario: 主题属性着色

- **WHEN** 构建选择菜单
- **THEN** 使用主题 `colorSurface`/`colorOnSurface` 而非字面颜色值
