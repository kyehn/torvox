# text-selection Specification

## Purpose
文本选择的启动（长按/多击）、控制柄拖动与边缘滚动、选择菜单内容与锚定、全选与复制、打开链接/文件的对外行为契约，对齐 `DESIGN.md` 文本选择条款与 termux-app、ghostty-android-terminal 参考实现。

## Requirements

### Requirement: 长按启动选择

长按非空文本 MUST 经上游终端词选择语义选中该词并反色，随后出现左右控制柄；长按空白或无可选词的单元格 MUST 仅反色被长按单元格。选择状态 MUST 由终端持有并随滚动与新输出跟随文本。

#### Scenario: 长按选词

- **WHEN** 长按英文单词
- **THEN** 选区覆盖该词（按上游词边界语义）且出现左右控制柄

#### Scenario: 长按空白单元格

- **WHEN** 长按无内容单元格
- **THEN** 仅该单元格反色并显示粘贴菜单

#### Scenario: 选区随滚动跟随

- **WHEN** 选择激活期间新输出将文本推进回滚区
- **THEN** 选区端点跟随文本移动

### Requirement: 多击选择

双击 MUST 经上游语义选词，三击 MUST 选行，四击及以上 MUST 全选；单击消除选择 MUST 重置多击计数，使其后的快速单击不被误判为双击。

#### Scenario: 双击选词

- **WHEN** 双击单词
- **THEN** 选区覆盖该词并出现控制柄

#### Scenario: 三击选行

- **WHEN** 三击某行
- **THEN** 选区覆盖该行内容

#### Scenario: 消除后计数重置

- **WHEN** 选择激活时单击消除，随后在计时窗口内再次单击
- **THEN** 两次单击均不触发选词

### Requirement: 控制柄拖动

拖动控制柄 MUST 实时更新选区，宽字符单元格 MUST 吸附不被拆分；一端越过对侧端点 MUST 交换两端归属；拖动期间选择菜单 MUST 隐藏，抬手 MUST 按新选区几何重显菜单。

#### Scenario: 宽字符吸附

- **WHEN** 手柄停在双宽字符的后半格
- **THEN** 手柄吸附至该字符起始列

#### Scenario: 交叉交换归属

- **WHEN** 起点手柄越过终点手柄
- **THEN** 两端归属交换且选区保持非空

#### Scenario: 拖动隐藏菜单

- **WHEN** 抓住控制柄开始移动
- **THEN** 选择菜单不可见；抬手后菜单按新选区重显

### Requirement: 边缘滚动

手柄拖动触及视口上下边缘时，每次触点移动 MUST 使可视区域恰好滚动 1 行；手指停在边缘区内不移动时 MUST NOT 滚动。

#### Scenario: 下缘拖动逐行滚动

- **WHEN** 手柄拖至视口底部边缘外并持续移动
- **THEN** 每次触点移动视口滚动 1 行

#### Scenario: 手指静止不滚动

- **WHEN** 手指停在边缘区内不移动
- **THEN** 视口保持不动

### Requirement: 选择菜单内容

菜单条目 MUST 有且只有：无内容区域长按 → 粘贴，且剪贴板无文本时 MUST NOT 显示菜单；有内容区域 → 复制、分享、全选，选中文本为 URL 形态或选区起点存在 OSC 8 超链接时 MUST 含打开链接，选中文本为合理长度、无空格的文件路径形态时 MUST 含打开文件。条目 MUST 一次点击即生效。

#### Scenario: 剪贴板有文本时长按空白

- **WHEN** 剪贴板含文本且长按无内容区域
- **THEN** 菜单仅有粘贴

#### Scenario: 剪贴板无文本时长按空白

- **WHEN** 剪贴板无文本且长按无内容区域
- **THEN** 不显示菜单

#### Scenario: 内容区域完整条目

- **WHEN** 长按含 URL、OSC 8 超链接与文件路径形态文本的区域
- **THEN** 菜单为复制、分享、全选、打开链接、打开文件

#### Scenario: 一次点击即生效

- **WHEN** 点击复制
- **THEN** 立即写入剪贴板且无需二次确认

### Requirement: 菜单锚定与样式

菜单 MUST 位于选区附近且不与选区矩形相交：选区变更后 MUST 立即重显并重锚，贴视口边缘 MUST 翻转到另一侧，两侧均无空间时 MUST 隐藏。菜单样式 MUST 使用 Material 3 主题属性，MUST NOT 硬编码颜色。

#### Scenario: 全选后重锚

- **WHEN** 通过菜单触发全选
- **THEN** 菜单立即按新选区重锚且与选区矩形不相交

#### Scenario: 贴顶翻转到下方

- **WHEN** 选区贴住视口顶部使上方无空间
- **THEN** 菜单翻转到选区下方且不遮挡选区

#### Scenario: 两侧无空间时隐藏

- **WHEN** 选区高度使上下方均无处放置菜单
- **THEN** 菜单隐藏

#### Scenario: 主题属性着色

- **WHEN** 构建选择菜单
- **THEN** 使用主题 `colorSurface`/`colorOnSurface` 而非字面颜色值

### Requirement: 全选范围

全选 MUST 覆盖全部可选内容且仅涉及有内容区域（不含尾部空行与尾随空列）；全选后复制 MUST 输出该选区的折行感知文本。

#### Scenario: 尾部空行不入选

- **WHEN** 内容止于视口中部并执行全选
- **THEN** 选区界限不含其后的空行与行尾空列

#### Scenario: 全选复制内容正确

- **WHEN** 全选后点击复制
- **THEN** 剪贴板文本包含全部内容且软换行处无注入换行符

### Requirement: 打开链接与打开文件

打开链接 MUST 仅检查格式：选中文本非 URL 形态时 MUST 回退使用选区起点的 OSC 8 超链接 URI，经系统意图跳转且 MUST NOT 检查可达性；打开文件 MUST 仅检查路径格式与点击时文件是否实际存在，MUST 授予读写权限供其他应用回写，MUST NOT 附加文件位置限制。

#### Scenario: OSC 8 非 URL 文本打开

- **WHEN** 选中文本非 URL 形态但起点存在 OSC 8 超链接且点击打开链接
- **THEN** 经系统意图打开该超链接 URI

#### Scenario: 文件存在授予写权限

- **WHEN** 选中存在文件的路径并点击打开文件
- **THEN** 经系统意图打开并授予写权限

#### Scenario: 文件不存在时提示

- **WHEN** 路径格式匹配但文件不存在时点击打开文件
- **THEN** 提示无法打开且不发生跳转

### Requirement: 复制语义

复制 MUST 按折行感知拼接：软换行处 MUST NOT 注入换行符，行尾空白 MUST 按上游格式化裁剪。

#### Scenario: 软换行不注入换行

- **WHEN** 选区跨越自动折行的行
- **THEN** 复制文本在折行处直接拼接且无多余换行
