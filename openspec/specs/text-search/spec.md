# text-search Specification

## Purpose

终端文本搜索的能力边界。搜索由上游 `libghostty-vt` 的 `search::Search` 承担：软换行
跨行匹配、随输出增量同步、命中总数与导航滚动全部以上游为单一来源，本仓只做「上游
选区 → 按物理行的网格区间」的转换与视口内高亮。命中规模与查询长度须有上限以免拖住
输入线程。

## Requirements

### Requirement: 搜索走上游 search::Search

搜索 MUST 由上游 `libghostty-vt` 的 `search::Search` 承担，MUST NOT 自建匹配器：
搜索对象随 VT 线程存活，needle 设置、命中总数、导航（`select_next`/`select_prev`）
与视口命中（`viewport_matches`）全部走上游，本仓 MUST NOT 复制其匹配、软换行跨行或
增量同步逻辑。

上游命中的 `Selection` MUST 转为按物理行拆分的绝对网格区间（`row`/`start_col`/
`end_col`）：首行自命中起点到该行内容末尾，末行自 0 到命中终点，中间整行覆盖，且每行
末尾按行内容裁剪（行尾未写下的填充不高亮）。宽字符覆盖两列，命中端点落在其头/尾格时
起点回退到该宽字符的首列。

匹配语义以上游为准：字节精确，仅 ASCII 字母不区分大小写；因此本仓 MUST NOT 提供
区分大小写开关（MUST NOT 为该开关另建匹配路径）。

#### Scenario: ASCII 字母不区分大小写

- **WHEN** 以 `abc` 搜索且回滚含 `ABC`
- **THEN** 命中该行

#### Scenario: 非 ASCII 大小写不折叠

- **WHEN** 以 `čau` 搜索且回滚含 `Čau`
- **THEN** 不命中该行（上游只折叠 ASCII 字母）

#### Scenario: 查询按字面处理

- **WHEN** 查询含正则元字符（如 `a.b`）
- **THEN** 按字面匹配，不把 `.` 当通配

#### Scenario: 跨软换行的命中按物理行拆分

- **WHEN** 命中横跨软换行边界
- **THEN** 每个物理行各得一条区间，列号落在该行内，不越过网格宽度

#### Scenario: 宽字符命中覆盖两列

- **WHEN** 命中以宽字符起止
- **THEN** 区间覆盖该宽字符占据的全部列，尾格不另成命中

### Requirement: 查询长度与命中规模有上限

needle 字符数 MUST 不超过 `MAX_SEARCH_QUERY_CHARS`（128），超出直接判为无命中，
MUST NOT 截断——截断会让用户搜到另一个串的结果。命中规模上限以上游为准（上游
50k 窗口），本仓 MUST NOT 另设一份。

#### Scenario: 超长查询无命中

- **WHEN** 查询长度超过 128 字符
- **THEN** 返回 0 命中并出声记录，不进入扫描

### Requirement: 搜索高亮由原生按上游命中直接生成

视口高亮 MUST 由原生从上游命中的网格区间直接生成：绝对网格行折算为网格行的口径是
`gridRow = 绝对行 - (回滚长度 - 视口滚动偏移)`，`scrollOffset` 为 0 表示贴底。视图侧
MUST 只提供视口滚动偏移与两个主题色（当前命中的前景色、其余命中的选区色），MUST NOT
打包命中区间跨 JNI 传输——命中几何只有一份真相，即上游搜索结果。

当前选中命中的高亮 alpha MUST 为 255（完全不透明），其余命中 MUST 为 160 且仍走
「交换前景/背景再混合」的分支（alpha 阈值 128），使当前项在同色系里仍可区分。落在视口
外的命中 MUST NOT 写入高亮。

清除 MUST 以显式调用完成（关闭搜索或命中为空时），且 MUST 置脏标志，使无 PTY 流量的
空闲屏也能在下一帧消掉陈旧高亮。

#### Scenario: 视口折算

- **WHEN** 回滚长度 100、滚动偏移 0（贴底）、命中在绝对行 110
- **THEN** 高亮写在网格行 10

#### Scenario: 上滚后命中移出视口

- **WHEN** 同一命中在滚动偏移 20 下折算到网格行 30，而视口只有 20 行
- **THEN** 不写入任何高亮

#### Scenario: 当前命中与普通命中配色不同

- **WHEN** 视口内同时存在选中命中与其他命中
- **THEN** 选中命中的 alpha 为 255，其余为 160

#### Scenario: 清除后立刻消掉陈旧高亮

- **WHEN** 关闭搜索或当前查询无命中
- **THEN** 高亮列表为空且渲染态被置脏，下一帧不再残留旧高亮

### Requirement: 定位保留上下文

上一个/下一个命中定位 MUST 把命中行居中：上游定位策略只保证命中可见，命中会贴视口
上下缘，因此视图侧 MUST 在导航后把命中行居中，命中行上下各留约半屏可读内容。

#### Scenario: 定位留上下文

- **WHEN** 通过下一个跳到位于屏幕外的命中
- **THEN** 视口滚动后该命中行不在首行或末行，上下保留上下文行

### Requirement: 导航复用上游搜索状态

命中导航（上一个/下一个）MUST 走上游 `select_next`/`select_prev`，MUST NOT 因导航重新
扫描回滚区，也 MUST NOT 在 UI 侧维护命中表或索引算术（上游持有选中态与总数）。

#### Scenario: 连续导航不重扫

- **WHEN** 连续点击下一个三次且期间无新输出
- **THEN** 三次定位均来自同一搜索对象，不重新扫描

#### Scenario: 导航下标由上游定义

- **WHEN** 设置 needle 后连续导航
- **THEN** 首次命中的下标为 0（最新命中），继续导航朝更旧内容前进，走到最旧后回绕到最新

#### Scenario: 无命中时导航无选中态

- **WHEN** 查询无命中
- **THEN** 导航返回 null，UI 清空选中态
