# settings-propagation Specification

## Purpose

设置下发的范围语义：live 设置推送全部会话并即时生效，spawn-time 设置仅影响新建会话。本能力覆盖设置存储到 Rust 会话之间的可观测下发契约。

## Requirements

### Requirement: live 设置推送全部会话

主题、字体等 live 设置变更 MUST 推送到全部现存会话并即时生效，MUST NOT 只作用于当前会话。

#### Scenario: 主题切换作用全部会话

- **WHEN** 用户切换终端主题且存在多个会话
- **THEN** 全部会话的配色同时更新，无需重建会话

#### Scenario: 字体变更作用全部会话

- **WHEN** 用户变更主字体且存在多个会话
- **THEN** 全部会话的渲染字体同时更新

### Requirement: spawn-time 设置仅影响新建

启动入口等 spawn-time 设置 MUST 只影响新建会话，MUST NOT 追溯修改现存会话的进程与环境。

#### Scenario: 启动入口变更不影响现存会话

- **WHEN** 用户修改 Shell 启动入口后查看现存会话
- **THEN** 现存会话仍运行原入口进程，仅新建会话使用新入口

### Requirement: 防抖写入只保留最新编辑

引导 URL 的防抖流 MUST 以最新值为准：持久化阻塞导致缓冲饱和时 MUST 丢弃旧编辑，
MUST NOT 丢掉最后一次输入。`latestBootstrapUrlEdit()` 与最终落盘值 MUST 一致。

#### Scenario: 慢写入期间连续编辑

- **WHEN** 首次 DataStore 写入被阻塞，用户继续输入多个 URL
- **THEN** 最新编辑仍可从仓库读取，解除阻塞后落盘的也是该值

### Requirement: 文本框只吞掉自己刚写下去的那一次回流

设置项文本框 MUST 只忽略「自己刚写入的那一次」回流（值相等即吞），MUST NOT 用一个
「编辑过」布尔闩把整个编辑期钉住：清除应用数据后存储值变空串而闩仍为真，输入框继续
显示清除前的旧值，而安装读到的是空串，两者静默分叉。

#### Scenario: 清除应用数据后输入框回填

- **WHEN** 用户在引导 URL 框输入过内容并确认清除应用数据
- **THEN** 输入框显示清除后的空值，与安装实际使用的值一致

#### Scenario: 防抖回流不回灌正在输入的字符

- **WHEN** 用户连续击键输入 URL，防抖落盘后回流值抵达
- **THEN** 输入框内容不被回流覆盖

### Requirement: 清除应用数据作废清除前的待写编辑

清除应用数据 MUST 作废**清除之前**编辑的引导 URL：那一版的待写值 MUST NOT 在清除
之后落盘，MUST NOT 重建已被删除的 `preferences_pb`，MUST NOT 让「已清除」的提示变成
假话。

作废 MUST NOT 依赖「停用写入的窗口恰好覆盖待写值的到期时刻」：清除要删目录并重建
prefs，耗时与防抖窗口（300ms）互不相干，故清除之前的编辑 MUST 由**清除轮次**作废，
无论它何时到期。清除之后的新编辑 MUST 照常落盘。

#### Scenario: 重新武装早于防抖到期时仍不落盘

- **WHEN** 用户在清除应用数据之前编辑过引导 URL，清除完成（写入重新武装）早于该编辑
      的防抖窗口到期
- **THEN** 该 URL MUST NOT 落盘，存储值 MUST 保持清除后的空值

#### Scenario: 清除之后的新编辑照常落盘

- **WHEN** 用户在清除应用数据之后再次编辑引导 URL
- **THEN** 该 URL MUST 在防抖窗口之后落盘，且 `latestBootstrapUrlEdit()` 与落盘值一致

### Requirement: 清除应用数据必须同时清空内存态与文件态

清除应用数据 MUST 使设置存储的**内存态与文件态同时归零**：MUST 先经存储本身
清空全部键，再删除持久化目录。MUST NOT 只删文件——存储单例缓存着已读入的状态，
只删文件时它仍按旧值对外供给，下一次写入还会把旧值整份写回，「已清除」的提示
遂成假话。

清除后 MUST NOT 有任何设置项以清除前的值继续生效：界面读到的值、落盘的值与
后续写入所携带的值 MUST 一致地为空或缺省。

#### Scenario: 清除后界面读到的是缺省值

- **WHEN** 用户设置过字号、Shell 入口与字体族后清除应用数据
- **THEN** 设置读取到的 MUST 是各自的缺省值，MUST NOT 仍是清除前的值

#### Scenario: 清除前的值不得在后续写入中复活

- **WHEN** 清除应用数据后用户再改动任一设置项
- **THEN** 落盘文件 MUST 只含清除后的新值，MUST NOT 带回清除前的任何设置项
