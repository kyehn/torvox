# docs/STATUS.md 变更记录

`docs/STATUS.md` 是「未被完全确认解决的问题」清单：只收录尚未完全确认解决的问题，
确认解决即从清单移除。该文件不允许修改，其历史变动只散落在提交里，故在此按版本留档。

## 0. 口径

- 定位方式：日期 + 该次提交的唯一一行说明。规范禁止在文档中出现提交哈希，故不写哈希。
- 条目按各版原文摘录（含当时的措辞），只归并同一版里的子项。
- 每节的「新增 / 移除」相对上一版而言。
- 本文件只记录，不代替 `docs/STATUS.md`：当前内容以该文件自身为准。
- 清单本身只增删条目、不改历史：某一项被移除即表示当次提交认为它已解决，
  后续若再次复现会作为新条目重新加入（第 4 节的裁剪即为此）。
