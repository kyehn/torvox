# 持久参考库

跨会话有效的外部事实与参照面记录：只收「需要反复查证、且无法从仓库内代码直接得出」的内容。行为与架构仍以 `docs/specification/` 为准。

## 格式

每个文件一套固定骨架：

- `# <对象名>`：文件标题即被记录对象。
- `## 0. 来源与口径`：来源链接（上游仓库、参考锚点）与阅读口径。
- `## N. …`：正文章节，编号自 1 起顺延。
- `### N.M …`：章节内小节，编号随所属章节。

章节标题不带编号前缀以外的修饰词；正文中的「见 N.M」指向同文件的小节。
