# velo-android 深度审查

- 来源：https://github.com/yhzion/velo-android
- 审查快照：2026-11-27，默认分支工作树；不记录提交哈希。
- 覆盖方式：枚举全部受版本控制文件后逐文件完整读入并计算 SHA-256；核心实现按声明与关键片段逐行复核。二进制与许可证/锁文件/生成表仍完整读入并登记哈希，但不逐行复述内容。
- 本地核对：下列本地文件均已实际打开阅读，核对结论只落在既有结构上。

## 审查结论

仓库定位：Rex 的 unofficial Android 客户端；终端与渲染全在 Zig 核心，Kotlin 只管界面与平台服务。与本地“Rust 核心 + Kotlin UI”的分层最可比。

### 分层

`docs/native-architecture.md` 明确两层：

- `native/` → `libvelocore.so`：Zig 0.17.1，静态链接 libghostty-vt 1.0.1 C ABI。负责 TLS、WebSocket、Rex 控制/数据协议、会话/窗口/布局/块状态、事件、重连、终端仿真、Kitty 图片、OpenGL ES 3 渲染、键编码、选择与复制文本。
- `app/`：Kotlin + Compose，负责 Activity、各屏幕、SurfaceView、触摸/键盘/IME 转发、设置与远端持久化、每个远端一个 core、应用内 Tailscale 节点、Android 字体字形栅格化请求。

### 关键机制

- TLS 不是直接采用 Zig 标准库：`net/TlsClient.zig` 是 `std.crypto.tls.Client` 的修补副本，补齐 CA 路径长度/nameConstraints/extendedKeyUsage/未知关键扩展检查，并对服务器发来的每个长度做边界比较（release 构建为 `ReleaseFast`，不能依赖上游安全检查）。根证书来自 `AndroidCAStore`，App 每次启动复制 PEM 到 `no_backup/user-cas`，失败时回退 `/system/etc/security/cacerts`，并有 5 秒超时避免首连卡死。
- WebSocket 自己实现 RFC 6455：HTTP/1.1 upgrade、掩码客户端帧、分片、ping/pong/close，无压缩。控制通道是 JSON one-object-per-message，数据通道是二进制 HELLO/WELCOME/RESUME 与 Rex APC 事件。
- JNI 契约非常细：`start/connect/selectSession/command/key/paneSurface/paneScale/panePan/panePreview/paneResume/paneSuspend/paneTouch/paneCopy/paneBracketedPaste/forwardOpen` 等，handle 是不透明 `Long`，所有调用快速返回，工作发生在 core 线程。
- 窗格表面生命周期是重点：`panePreview` 供标签总览复用同一 surface 但不抢终端；`paneSuspend` 在离开屏幕/被遮挡时调用，`paneResume` 在回来时恢复，避免解锁或开关侧栏时抢走桌面端终端；`fit`/`touch` 两个 op 明确区分“尺寸落定”和“手指按下”。
- 缩放分 live 与最终态：捏合中拉伸已有字形，结束时才按最终字号重绘一次；平移先滚 oversized grid，再进入历史，鼠标跟踪或 alternate scroll 由 core 处理。
- 119 个测试文件，覆盖 Kotlin 与 Zig 两侧的协议、布局与生命周期；`unsafe` 计数为 0（Zig 不用该关键字，不能据此推断内存安全）。

### 验证与风险

- 依赖 Rex 服务端协议 revision 18 与 Tailscale MagicDNS/HTTPS 证书；证书进入公共 ledger，隐私取舍需明确告知。
- 自实现 TLS/WebSocket 和修补标准库意味着升级 Zig 时必须重新审计补丁；这部分代码量和维护成本远高于普通终端 UI。
- 远程客户端没有本地 PTY；把它的键编码/表面生命周期直接套到本地会引入不存在的远端状态机。

### 本地取舍

值得逐条对照的是 `paneSurface/panePreview/paneSuspend/paneResume/fit/touch` 的语义：本地 Surface 生命周期如果将来支持多窗格或预览，这套“谁拥有终端、何时重新 fit”的协议可以避免重复 resize 和抢焦点。TLS 与 Rex 协议不采纳。
