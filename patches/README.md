# Patches — local modifications to upstream dependencies

This directory contains only `.patch` files (diffs), **not** vendored source
copies. The patched crates are generated by `scripts/bootstrap-libghostty.nu`
into `generated-patches/` (gitignored, created at build time).

## Patch files

| File | Applies to | Purpose |
|------|-----------|---------|
| `libghostty-vt-correctness.patch` | `vendor/ghostty/` | Ghostty C source VT correctness fixes |
| `libghostty-vt-sys.patch` | `libghostty-vt-sys` crate | Low-level C binding adjustments |
| `libghostty-vt.patch` | `libghostty-vt` crate | High-level Rust API adjustments |

## Upstream sources

- **Ghostty C source**: <https://github.com/ghostty-org/ghostty>
- **libghostty-rs** (Rust wrappers): <https://github.com/Uzaaft/libghostty-rs>

## How it works

1. `scripts/bootstrap-libghostty.nu` clones both upstream repos (cached in
   `.cache/`) and applies the patches above
2. Output goes to `generated-patches/libghostty-vt/` and
   `generated-patches/libghostty-vt-sys/`
3. `Cargo.toml` uses `[patch."..."]` to point Cargo at these generated directories
4. The Nix `shellHook` runs the bootstrap script automatically on `nix develop`

## Updating

To update patches after modifying the generated crates:

```bash
# Regenerate patches
diff -ruN .cache/libghostty-rs/crates/libghostty-vt-sys/ generated-patches/libghostty-vt-sys/ > patches/libghostty-vt-sys.patch
diff -ruN .cache/libghostty-rs/crates/libghostty-vt/ generated-patches/libghostty-vt/ > patches/libghostty-vt.patch

# Verify they apply cleanly
rm -rf generated-patches/
nu scripts/bootstrap-libghostty.nu
cargo check
```
